# ShellEmulator

## 1. Общее описание
**ShellEmulator** — это Windows Forms приложение, эмулирующее работу консоли с возможностью работы с виртуальной файловой системой (VFS), загружаемой из CSV-файлов.  
Приложение поддерживает базовые команды (`ls`, `cd`, `cat` и др.), выводит приветственное сообщение и конфигурацию при запуске, а также может выполнять стартовые скрипты.

Основные возможности:
- Работа с виртуальной файловой системой (VFS).
- Навигация по директориям и вывод их содержимого.
- Просмотр содержимого файлов (включая бинарные, отображаемые в Base64).
- Автоматическая загрузка VFS и выполнение стартовых скриптов при запуске приложения.

## 2. Описание функций и настроек

### Аргументы запуска
- `--vfs <путь>` — загрузка VFS из CSV файла.
- `--script <путь>` — выполнение стартового скрипта (список команд).

### Команды в эмуляторе
- `exit` — завершение работы приложения.
- `ls [путь]` — вывод содержимого директории или информации о файле.  
  - `d <имя>` — директория.  
  - `- <имя>` — файл.
- `cd <путь>` — переход в указанную директорию.
- `vfs-info` — информация о загруженной VFS (имя, SHA-256).
- `vfs-load <путь>` — загрузка новой VFS из CSV.
- `vfs-cat <путь>` — вывод содержимого файла. Если файл бинарный, содержимое выводится в Base64.

### Поведение при загрузке
- Если указан `--vfs`, приложение загружает виртуальную файловую систему.
- Если указан `--script`, выполняется последовательность команд из файла (игнорируются строки, начинающиеся с `#` или `//`).
