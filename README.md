# ShellEmulator

## 1. Общее описание
**ShellEmulator** — это Windows Forms приложение, эмулирующее работу командной строки.  
Оно предоставляет графический интерфейс с окном вывода, полем ввода и кнопкой отправки, имитируя поведение терминала.  
Поддерживаются базовые команды-заглушки (`ls`, `cd`, `exit`) и выполнение стартового скрипта при запуске. 

## 2. Описание функций и настроек

### Основные функции
- `InitUI()` — инициализация интерфейса: окно с выводом, строка ввода и кнопка.
- `PrintWelcome()` — вывод приветственного сообщения.
- `PrintConfig()` — отображение текущих параметров запуска (пути VFS и скрипта).
- `AppendOutput(string str)` — добавление текста в вывод.
- `RenderPromt()` — рендеринг приглашения вида `user@host:$`.
- `ProcessInput(string line)` — обработка введенной команды.
- `CmdStub(string name, string[] args)` — заглушка для команд (`ls`, `cd`).
- `RunStartupScript(string path)` — выполнение команд из скрипта при старте.
- `OnResizeControl()` — адаптивная подгонка элементов интерфейса при изменении размера окна.
- `OnInputKeyDown()` / `OnButtonClick()` — обработчики событий для ввода текста и кнопки.

### Поддерживаемые команды
- `exit` — завершает работу приложения.
- `ls` — выводит заглушку с аргументами.
- `cd` — выводит заглушку с аргументами.
- Любая другая команда → сообщение об ошибке.

### Параметры запуска
Программа поддерживает аргументы командной строки:
- `--vfs <path>` — путь к виртуальной файловой системе (пока заглушка, используется для отображения).
- `--script <path>` — путь к скрипту, который выполняется при старте.

## 3. Описание команд для сборки проекта и запуска тестов

### Сборка
Проект является WinForms-приложением на C#.  
Для сборки используйте **.NET SDK**:

```sh
dotnet build
```
