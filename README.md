# ShellEmulator

## 1. Общее описание
**ShellEmulator** — это Windows Forms приложение, эмулирующее работу командной строки.  
Оно предоставляет графический интерфейс с окном вывода, полем ввода и кнопкой отправки, имитируя поведение терминала.  
Поддерживаются базовые команды-заглушки (`ls`, `cd`) и команда выхода (`exit`).  

## 2. Функции и настройки

### Основные элементы интерфейса:
- **outputBox** — окно вывода текста (многострочное, только для чтения, со скроллингом).
- **inputBox** — поле ввода команд.
- **sendButton** — кнопка "Enter" для отправки введенной команды.

### Основные функции:
- `InitUI()` — инициализация интерфейса и элементов управления.
- `OnResizeControl()` — динамическая подстройка размеров элементов при изменении размера окна.
- `PrintWelcome()` — вывод приветственного сообщения.
- `AppendOutput(string str)` — добавление строки в окно вывода.
- `RenderPromt()` — отображение приглашения вида `username@hostname:$`.
- `OnInputKeyDown()` — обработка нажатия **Enter** в поле ввода.
- `OnButtonClick()` — обработка нажатия кнопки **Enter**.
- `ProcessInput(string line)` — обработка введенной команды:
  - `exit` — закрытие приложения.
  - `ls` — заглушка, вывод аргументов.
  - `cd` — заглушка, вывод аргументов.
  - неизвестная команда → вывод ошибки.
- `CmdStub(string name, string[] args)` — вывод информации о вызванной команде и её аргументах.

### Настройки:
- Окно по умолчанию: `800x600`.
- Заголовок окна: `"Эмулятор - [username]@[hostname]"`.
- Автоматическая прокрутка окна вывода к последней строке.

## 3. Сборка и запуск

### Сборка проекта
```bash

```
